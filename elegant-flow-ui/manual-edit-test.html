🔍 Critical Layout Tests

  • Header: Check all buttons are visible and don't overlap
  • Split Panels: Verify 40/60 split on desktop
  • Tool Panel: Scroll through all accordion sections
  • Image Panel: Test zoom in/out and pan functionality
  • Resizable Divider: Drag to resize panels
  • Mobile View: Resize to <768px and check stacking
  • Toolbar Overflow: Resize to 320px width
  • Loading States: Trigger an edit operation
  • Comparison View: Toggle compare button
  • Metadata Overlay: Toggle info button

📐 Responsive Breakpoints to Test

  • Desktop (>1024px): Full split layout, all features visible
  • Tablet (768-1024px): Adjusted split (35/65)
  • Mobile (480-768px): Stacked layout
  • Small Mobile (<480px):< /strong> Compact stacked layout

⌨️ Keyboard Shortcuts to Test

  • Ctrl+Z - Undo
  • Ctrl+Y - Redo
  • Ctrl+R - Reset
  • Ctrl+S - Download
  • Ctrl+0 - Zoom fit
  • Ctrl++ - Zoom in
  • Ctrl+- - Zoom out
  • Escape - Go back

🐛 Known Issues to Watch For

  • Toolbar Overflow: ImagePanel toolbar may wrap on narrow screens
  • Accordion Overflow: Tool content may overflow on short screens
  • Comparison Slider: May be difficult to use on touch devices
  • Metadata Overlay: May overlap controls on small screens
  • Divider Grabbing: May be too thin on touch devices
  • Long Messages: Loading messages may wrap awkwardly
  • Pinch Zoom: May conflict with browser zoom on mobile
  • Aspect Ratios: Very wide/tall images may not fit properly

📝 How to Report Issues

For each issue found, document:

  • Component: Which part broke (e.g., "ImagePanel toolbar")
  • Screen Size: Width x Height where issue occurs
  • Description: What's wrong
  • Steps: How to reproduce
  • Screenshot: Visual evidence
  • Severity: Critical / Major / Minor
